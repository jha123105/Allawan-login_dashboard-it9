# Student Login and Registration System

A simple web-based Student Login, Registration, and Dashboard system created using HTML and CSS.

## Features

- User Login Page
- User Registration Page
- Student Dashboard
- Student Records Table
- Logout Navigation
- Responsive and clean interface
- Simple page-to-page navigation
- GitHub version control

## Technologies Used

- HTML5
- CSS3
- Git
- GitHub
